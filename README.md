# 📚 BookFM - Read & Relax

A modern book reading platform that combines the joy of reading with curated music playlists to create the perfect reading atmosphere.



🔗 **Live Site**: [https://bookfm.vercel.app/](https://bookfm.vercel.app/)

## ✨ Features

### 📖 Reading Experience
- **Pre-loaded Library** - Curated collection of books across multiple categories
- **Custom Uploads** - Upload and read your own books
- **Table of Contents** - Quick navigation panel on the left side
- **Customizable Reading**
  - Adjustable font sizes
  - Multiple font themes
  - Line height controls
  - Reading progress tracking

### 🎨 Personalization
- **Dark/Light Mode** - Toggle between themes for comfortable reading
- **Reader Customization** - Tailor the reading experience to your preferences
- **Responsive Design** - Seamless experience across all devices

### 🎵 Music Integration
- **Music Panel** - Dedicated right-side panel for ambient music
- **Curated Playlists** - Background music to enhance your reading
- **Multiple Genres**
  - Lofi Beats
  - Ambient
  - Jazz Vibes
  - Classical
  - Piano
  - Nature Sounds
  - Meditation
  - Acoustic
  - Chillhop

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/bookfm.git
cd bookfm
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Run the development server
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🎯 Usage

### Reading Books
1. Browse the pre-loaded library or upload your own book
2. Click on a book to open the reader
3. Use the left panel to navigate chapters via Table of Contents
4. Customize your reading experience with font, size, and spacing controls

### Playing Music
1. Access the music panel on the right side
2. Choose from various music categories
3. Play ambient music while reading for enhanced focus

### Theme Switching
- Toggle between dark and light modes using the theme switcher
- Preferences are saved automatically
